# Growth Accelerator Tiers

[![Curseforge](https://img.shields.io/curseforge/dt/1316818?style=for-the-badge&label=Downloads&logo=curseforge&color=F16436)](https://www.curseforge.com/minecraft/mc-mods/growth-accelerator-tiers)
[![GitHub](https://img.shields.io/badge/GitHub-Growth--Accelerator--Tiers-181717?style=for-the-badge&logo=github)](https://github.com/SathLabs/Growth-Accelerator-Tiers)

This is a small mod adds 3 new tiers to the Applied Energistics 2 Growth Accelerator

### Cranked Growth Accelerator

*   Cannot be connected to your ME Network
*   Will not accept power directly
*   Can only be powered with a Hand Crank
*   Eight times the base speed, but will run out of power almost instantly

### Boosted Growth Accelerator

*   Eight times the base speed, but will consume ~3 times the energy
*   Will conflict with other Boosted Accelerators when placed around the same farmland

### Directional Growth Accelerator

*   Useful for Budding Blocks, such as the Amethyst or Certus Budding Block
*   Allows you to specify the Direction of the Budding Cluster to grow in
*   Will conflict with other Directional Accelerators when placed around the same farmland
*   Currently supports the following mods
    *   Minecraft
    *   Applied Energistics 2
    *   ExtendedAE
    *   Geores
    *   Just Dire Things
    *   Neo Eco AE (1.21.1 only)

Any other mods you'd like to see supported? Open a feature request on GitHub and I'll make sure to get it added!
